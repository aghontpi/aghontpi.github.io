Running an Personal Assistant agent 24/7, that actually works - July 2026

Written by Bluepie with ♥ on July 12, 2026 in Tech AI

Intro

I started to use the Hermes Agent and OpenClaw. They burn a lot of tokens for what they do, but they do get the job done. When I’m out of home, I can just message them or email them (cuz they manage their own email address, because i’ve created it for them), but they are good only based on the underlying model they are being used on.

For example: torrent search and download, extensive research on a topic, using built-in search and integrations (since I already have skills for those), and even coding minor features with some guidance.

I usually use one-off agents for my use. For example, I wanted to download all episodes of Witch Hat Atelier (Tongari Boushi no Atelier, at the time of weekly release, ep 10⁄11 at that time), and there was not a single torrent which had all the episodes at that time. I opened VS Code (I was using DeepSeek V4 Flash) and asked it to create a readme file of all magnetic links for all released episodes of the show. I gave it an example like episode 2 and which site I preferred to download from. It then used its VS Code browser tool, along with a combination of other tools, to fetch the torrent links quickly. It even validated and reported the findings on them, so the next thing was me downloading them… but for that I have a separate skill that does this: https://github.com/aghontpi/dot-configs-ai/blob/main/skills/qbittorrent/SKILL.md that downloads the magnetic links directly to qBittorrent on my server.

The Cost

I’ve been advocating to use DeepSeek V4. Last month I used just under $10 worth of AI credits on the DeepSeek API.

This month I decided to try out OpenCode Go. They offer $5 for the first month but offer more out of the AI tokens (from their site, equivalent to $60 worth of credits). I’m only sticking to DeepSeek! So it should be fine.

Opens a Lot of Doors

Since the DeepSeek API is low cost, it opens a lot of doors for opportunities where it can be used, like project integration to make life easier. Im maintaining a project that I use for downloading offline music; one thing is that I have to manually search, select, and find the appropriate songs for each one, but with the AI integration, I can make it work autonomously, which is great. I can run it and I will know for sure, 95% - 99%, it will capture the right song, so I don’t have to worry about it. Instead of buying ChatGPT for $20 a month when it can’t interact with my server or do any of the nuanced things I want done, I just pay a small set of token price to use a personal agent that actually works for me and gets things done!

Another example is: I wanted an APK to be reversed, but ChatGPT straight up denied it. I just gave my old notes and instructions to patch an APK to Hermes. It downloaded Apktool and other tools necessary itself, set up a workspace, and proceeded to work on it. Even though it got stuck a few times, I just logged in, directed it to the right path, and got back to what I was doing. It finished the task, which was great!

What I Never Experienced Before

I never used AI agents 27⁄7 up until this point, and never ran anything like that on my server, but after DeepSeek made it possible with its affordable AI, I don’t want to use free AI models (the free AI models that you consume from APIs collect your data). Since it’s a personal AI, I don’t want it to be collecting logs on me. OpenCode Go says they don’t store the logs, but I still don’t give it permission to access my emails, used it as a bot for a month and my verdict is good. Initially I tried OpenClaw, but I switched to Hermes; it’s more stable, uses fewer tokens, and gets things done. It’s good; it’s like a friend who gets things done. Sometimes they mess up, but you can give them instructions and they will finish it.

let me share how many tokens I used on 24⁄7 agents this month! It’s around 700 million tokens!

Trust me, it didn’t cost me what you see in the dashboard image. I used my OpenCode Go subscription, which was good. Next month, I would use another account and consider using the subsidy of $5 instead of $10 on this account.

Modes of Configuration

I’ve configured email, Telegram, and Discord for this, and it’s been running on my server 24⁄7 for a long time now, creating a new session and removing any old sessions if present.

Since I started using this with Telegram, I can quickly record a voice note and dispatch a task to it; it will do it on its own. One thing I noticed is that threading mode works great and helps keep things in separate places, otherwise all the chats and things will be clubbed together and will be a mess to follow, making the context muddy.

Like I said, it knows my torrent server and media server actions, like how to download things there (media, books & comics, etc.). Additionally, whenever I do a new action, it self-learns a new skill to work with it, which is great! I never use OpenClaw now; it’s bloated and Hermes is much better for me in terms of token usage and its knowledge of me when doing tasks.

Bad Experience with OpenClaw

I had a bad experience with OpenClaw. Initially, I was hosting both OpenClaw and Hermes. OpenClaw is bloated, uses a lot of tokens, has lots of bugs, and it’s vibe-coded from scratch. when it got first released it had lots of security flaws; now it’s improving, but each update breaks a lot of things. Last time, after an update I remember I had to spend 40 mins debugging what went wrong and fix it manually. Since I run these things inside a container on my server and protect them with a custom HTTP protected area, on top of that protect them with a username and password, I could use Tailscale with it, which I already have configured on my server.

OpenClaw or Hermes?

If you ask me OpenClaw or Hermes as of now (July 2026), I’d say Hermes, because it works and compared to OpenClaw, it’s not as bloated.
